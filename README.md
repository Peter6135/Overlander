## Tentang Overlander

Proyek ini baru dimulai dari basis kode [NULUNG](https://github.com/Peter6135/nulung) (marketplace jasa lokal Kota Magelang), lalu akan dirombak jadi website travel agency yang menonjolkan pencarian destinasi berbasis lokasi dan ulasan tamu langsung.

Dokumentasi fitur/skema akan ditulis ulang di sini seiring pengembangan.
